## 🚀 1. How You Can Contribute

We welcome contributions that improve stability, introduce clean UI components, optimize Lua performance, or fix bugs. Here is how you can help:

* **Bug Fixes:** Resolving UI scaling glitches, broken execution hooks, or unexpected script crashes.
* **Performance Optimizations:** Streamlining loops, garbage collection, and memory footprint in custom components.
* **Feature Enhancements:** Proposing new UI modules, themes, or helper utilities that fit the core architecture.
* **Documentation Improvements:** Keeping README setups, API definitions, and inline code comments clear and accurate.
