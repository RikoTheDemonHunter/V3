## 🎯 1. Repository Purpose & Scope

The **V3 (Avery Hub)** repository serves as the central, official distribution vector for high-performance Lua UI systems, modular execution frameworks, and custom client-side automation tools. Built with a focus on modularity, clean interface design, and seamless user execution, this repository houses:

* **Core Execution Frameworks:** Clean, responsive UI libraries optimized for stability and low-latency interaction.
* **Modular Lua Utilities:** Standalone and integrated utility modules engineered for high adaptability across custom environments.
* **Security & License Monitoring:** Built-in integrity verification models synced directly with **Avery Bot** for real-time asset protection.

This repository is maintained as a personal, dedicated project to showcase advanced UI construction, optimized scripting techniques, and efficient user experience design.

## 🤝 2. Expected Community Behavior

Whether interacting on GitHub, participating in the Discord server, or testing raw scripts, all community members, testers, and collaborators are expected to adhere to the following standards:

### 🟢 Positive Standards
* **Constructive Feedback:** Provide clear, actionable bug reports and feature suggestions with precise execution logs or UI errors.
* **Respect Original Authorship:** Always credit the underlying framework, design choices, and core developer (**Avery / RikoTheDemonHunter**) when referencing or discussing the repository.
* **Supportive Collaboration:** Help fellow users in designated Discord support channels regarding environment setup, execution issues, or configuration tweaks.

### 🔴 Prohibited Behavior
* **Toxic or Disruptive Conduct:** Harassment, hate speech, spamming repository issues, or targeting maintainers and community members will not be tolerated.
* **Malicious Code Submission:** Attempting to submit pull requests or code additions containing obfuscated malicious code, backdoors, or telemetry grabbers.
* **Exploitation of Community Infrastructure:** Using official channels or open issue trackers to distribute leaked scripts, stolen assets, or unauthorized third-party loaders.
